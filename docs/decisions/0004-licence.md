# 0004. Licence

- **Status:** open, 2026-11-14
- **Decision needed from:** Terra Howard

## Context

The repository is headed for GitHub as a public project. The other CAT implementations found so far use MIT
(Fastly, Eyevinn, jedisct1) and BSD-2-Clause (Quicr). CTA's patent policy, noted in
[decision 0002](0002-spec-sources.md), is one reason to weigh a licence with an explicit patent grant.

## Options

- **Apache-2.0:** permissive, with an explicit patent licence from contributors.
- **MIT:** permissive and short, matching most other implementations; no explicit patent grant.
- **BSD-2-Clause:** similar to MIT.

## Decision

Not made. No licence file is added until it is.
